# 画像命名ルール

ページはディレクトリで、ファイル名はHTMLから機械的に決める。機械的に決まらない場面だけ名前を考える。

## 形式

```
/img/{ページ}/{セクション}_{要素}_{番号}_{版}.{拡張子}
```

| 部分 | 決め方 | 例 |
| --- | --- | --- |
| ページ | URLの階層。2ページ以上で使う画像は `common` | `top/` `service/web/` `common/` |
| セクション | セクションのclass名。id・Modifierがあればそちらを優先 | `hero` `about` |
| 要素 | 画像に一番近い子要素名。セクション直下なら省略。背景・アイコン・ロゴは `bg` `icon` `logo` | `card` `bg` |
| 番号 | 追加順の2桁。100枚を超えそうなら3桁 | `01` |
| 版 | 同じ画像の派生。デバイス → 状態 → 解像度の順 | `sp` `hover` `thumb` `@2x` |

例：`hero_01.jpg`、`service_card_01_sp.jpg`、`header_icon_01_hover@2x.svg`

## ルール

- 番号より前が画像の区別、後ろが同じ画像の版。版を付けても番号は変えない
- 番号は1枚目から付け、削除しても詰めない・再利用しない
- 無印はPC版。WebPなどフォーマット違いは拡張子だけ変える
- 英小文字・数字のみ。部分の区切りは `_`、単語の区切りは `-`
- 色や形など見た目の情報は入れない
- クラス名の変更や画像の移動をしたら、画像もリネームして参照も直す

## ディレクトリ

```
/img/
  common/
    header_logo_01.svg
  top/
    hero_01.jpg
    hero_01_sp.jpg
    service_card_01.jpg
    gallery/              ← 枚数が多いセクションだけ切る
      gallery_01.jpg
  about/
    hero_01.jpg           ← 同じコンポーネントはディレクトリ違いで同名
```

- ファイル名はディレクトリに関係なくセクション名から書く。サブディレクトリに移しても `gallery_01.jpg` のままにし、`01.jpg` のように短縮しない
- 1セクションの画像が10枚を超えたら（または最初から10枚を超えると予測できる場合）、そのセクションのディレクトリを切る
- 分割はセクション単位で判断し、同じページ内で分割済み・未分割が混在してもよい

**例外**：CMSアップロードなどディレクトリが使えない環境では、先頭にページ名を付ける（`top_hero_01.jpg`）。

## 迷ったとき

| ケース | 対応 |
| --- | --- |
| 同じページで同じコンポーネントを複数回使う | 置いているセクション名を使う（`service_card_01` / `works_card_01`）。ディレクトリ違いの使い回しは、1ページに1つのコンポーネントだけ |
| 同じclassのsectionが並ぶ | 通し番号（`section_01`…）。まとまりが必要なら見出しから名前を付ける（`section-history_01`）か、HTMLにidを付ける。並び順を番号にするのは不可 |
| サムネイル | 縮小版は版（`gallery_01_thumb`）、別画像なら要素（`gallery_thumb_01`） |

## NG例

| NG | OK | 理由 |
| --- | --- | --- |
| `img01.jpg` | `hero_01.jpg` | 使用箇所がわからない |
| `hero_main.jpg` | `hero_01.jpg` | 2枚目を足すときに破綻する |
| `about_photo_01.jpg` | `about_01.jpg` | 直下の画像に要素は付けない |
| `hero_sp_01.jpg` | `hero_01_sp.jpg` | 版が番号より前にあり別画像に見える |
| `gallery/01.jpg` | `gallery/gallery_01.jpg` | フォルダの外で判別できない |

## 作業手順

画像を追加・命名するときは次の順で進める。

1. 画像を使うページのURLから、ディレクトリ（`/img/{ページ}/`）を決める
2. 画像を置くHTMLを確認し、セクションのclass名（id・Modifierがあれば優先）と、画像に一番近い子要素名を拾う
3. 対象ディレクトリの既存ファイルを確認し、同じ「セクション_要素」の最大番号 + 1 を番号にする
4. 版（`_sp` など）が必要なら、元画像と同じ番号の後ろに付ける
5. 機械的に決まらない場合は「迷ったとき」に従う。それでも決まらなければ、候補を挙げてユーザーに確認する
6. リネームした場合は、HTML・CSS・JS内の参照をすべて更新する
